## 💡 Overview

This repository contains the source code for the personal portfolio website of **Pabitra Lenka**, an aspiring Frontend Developer and UI/UX Designer based in Odisha, India.

Crafted with clean, semantic **HTML5**, modular **CSS3**, and vanilla **JavaScript**, this portfolio delivers a sleek developer experience and high interactivity without the heavy overhead of large client-side frameworks.

### Highlights:
- 📱 **Mobile-First Responsive Design**: Optimized across mobile screens, tablets, and large desktops.
- 🎨 **Modern Aesthetics**: Sleek dark/vibrant styling with smooth hover transitions and glassmorphism elements.
- ⚡ **Lightweight & Fast**: Zero unnecessary build steps, instant loading, and smooth frame rates.
- 🔍 **Interactive Components**: Filtering animations via MixItUp, touch slider via Swiper.js, and modal popups.

## 🚀 Quick Start

### Prerequisites
You only need a modern web browser (Google Chrome, Firefox, Safari, Microsoft Edge). No Node.js or build system is strictly required!

---

### Option 1: Direct Browser Opening
1. Clone the repository:
   ```bash
   git clone https://github.com/pabitralenka07/Portfolio_web.git
   ```
2. Navigate into the folder:
   ```bash
   cd Portfolio_web
   ```
3. Open `index.html` in your default browser:
   - **macOS**: `open index.html`
   - **Linux**: `xdg-open index.html`
   - **Windows**: `start index.html`

---

### Option 2: VS Code Live Server (Recommended)
1. Open the project in VS Code:
   ```bash
   code .
   ```
2. Install the extension **Live Server** (`ritwickdey.LiveServer`).
3. Right-click on `index.html` and choose **"Open with Live Server"**.
4. The site will automatically reload at `http://127.0.0.1:5500/index.html` whenever you save changes.

---

### Option 3: Local HTTP Server

Using Python:
```bash
# Python 3
python3 -m http.server 8000
```
Open `http://localhost:8000` in your web browser.

Using `npx`:
```bash
npx serve .
```

## ⚙️ Customization Guide

### 1. Profile & Personal Information
Open [index.html](file:///Users/pabitra/Desktop/Github/portfolio01/index.html) to update:
- **Name & Title**: Search for `home-title` and `home-subtitle` (`Hi, I'm Pabitra`).
- **Profile Photo**: Replace `pic.png` with your own square photo, or change the `<img src="pic.png">` path.
- **Social Links**: Update `href` attributes in `.home-social-links` and `.footer-socials`.
- **Contact Details**: Update your email, phone, and messaging links in `.contact-card` and `.my-info`.

### 2. Portfolio Projects
- To add or edit projects, find the `<div class="work-container">` block in [index.html](file:///Users/pabitra/Desktop/Github/portfolio01/index.html).
- Set the filter category using classes: `mix web`, `mix app`, or `mix design`.
- Project metadata (date, tech stack, client, preview link) can be customized directly inside each `.portfolio-item-details` container.

### 3. Services & Modals
- Service cards are located in `<section class="services">`.
- Each service has a dedicated `.services-modal` which pops up when users click *"View More"*. Add or remove bullet points as needed.

### 4. Theme & Styling
Colors, fonts, and spacing variables are configured at the top of [style.css](file:///Users/pabitra/Desktop/Github/portfolio01/style.css):
```css
:root {
    --primary-color: #your-accent-color;
    --title-color: #your-title-color;
    --text-color: #your-text-color;
    --body-color: #your-background-color;
}
```

## 📋 Pre-Deployment Checklist

Before deploying your portfolio publicly (e.g., to GitHub Pages, Vercel, or Netlify):

- [ ] Update `<title>` tag and `<meta name="description">` in `index.html`.
- [ ] Connect social media links (LinkedIn, GitHub, Twitter/X, Instagram).
- [ ] Replace placeholder contact email (`user@gmail.com`) and phone numbers.
- [ ] Ensure all project images, screenshots, and live demo links point to active URLs.
- [ ] Configure a working contact form endpoint (e.g. using [Formspree](https://formspree.io/) or [EmailJS](https://www.emailjs.com/)).
- [ ] Test on both desktop and mobile viewports.

## 🌐 Deploying to GitHub Pages

1. Push your repository to GitHub (branch `main`).
2. Go to your repository **Settings** > **Pages**.
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `/ (root)`
4. Click **Save**.
5. Your portfolio will be live at:
   ```
   https://pabitralenka07.github.io/Portfolio_web/
   ```
