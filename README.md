## 📌 About the Project

This portfolio website is designed to build my personal brand, highlight my technical abilities, and showcase my development projects through a clean and interactive interface.

It gives visitors an overview of my background, skills, work, and ways to connect with me.

## ✨ Features

- 🏠 **Home Section** — Personal introduction and profile.
- 🙋 **About Me** — Background and professional overview.
- 🎓 **Qualifications** — Education and experience timeline.
- 💻 **Skills Showcase** — Interactive skill categories and indicators.
- 🗂️ **Project Portfolio** — Project cards with category filtering.
- 🔍 **Project Details** — Popup interface for project information.
- 🛠️ **Services Section** — Interactive service detail modals.
- 💬 **Testimonials** — Slider-based testimonial section.
- 📩 **Contact Section** — Contact information and contact interface.
- 📱 **Responsive Design** — Adaptable layout for different screen sizes.
- 🧭 **Interactive Navigation** — Smooth navigation and mobile sidebar.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/pabitralenka07/Portfolio_web.git
```

### 2️⃣ Navigate to the Project

```bash
cd Portfolio_web
```

### 3️⃣ Run the Website

🌍 **Option 1 — Browser**

Open `index.html` directly in your browser.

💻 **Option 2 — VS Code Live Server**

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## ⚙️ Customization

Personalize the website by editing these files:

- 📝 **`index.html`** — Update your introduction, education, skills, projects, services, and contact details.
- 🎨 **`style.css`** — Customize colors, typography, spacing, animations, and layouts.
- ⚡ **`main.js`** — Modify navigation, filtering, popups, tabs, and interactive behaviors.
- 🖼️ **`pic.png`** — Replace the profile picture with your preferred photograph.

### ✅ Before Publishing

- 🔗 Update your social media links.
- 📬 Verify your contact information.
- 📚 Check education and experience details.
- 💼 Replace placeholder projects with your real work.
- 🖼️ Verify image paths and filenames.
- 📱 Test responsiveness on mobile and desktop.
- 🧪 Check navigation, popups, filters, and external links.
- 🔒 Never commit passwords, API keys, or private credentials.
